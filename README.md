## 项目实践

### AI 财务单据自动化处理系统

**独立产品设计与 Web 原型开发**

面向发票、收据和费用凭证，设计“上传 → 字段提取 → 异常复核 → 结构化导出”的流程。使用 OCR 提取信息，以 JSON Schema 约束输出，并校验金额关系、必填字段和重复单据；支持原文对照、人工修正以及 JSON / CSV 导出。通过记录预测结果和人工修正原因，建立典型错误的回归评测思路。

**Agent 产品设计与运营实践**

参与多 Agent 销售平台设计，覆盖客户维护、工作流搭建、转人工协同、A/B 测试与数据复盘。将销售 SOP 和历史对话沉淀为可配置的 Agent 能力，并参与自然语言驱动的工作流搭建及经营分析 Agent 设计。
